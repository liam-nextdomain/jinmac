# JinMac

**당신의 맥을 진맥(診脈)하세요.**

> 이 맥이 성능 안 딸리고 작업을 잘 해내고 있는 건가?
> 맥을 업그레이드 해야 하는데, 어떤 사양을 좀 더 올려야 할까?

JinMac은 1\~2주 동안 평소처럼 맥을 사용하면서 메모리·CPU·GPU·디스크·발열을 기록하고,
자주 한계 수준까지 갔던 자원이 뭐였는지 한국어 리포트로 알려 줍니다.
다음 맥을 살 때 업그레이드가 필요한 사양과, 그대로 둬도 되는 사양을 판단하는 데 도움을 줍니다.

## 받기

> **아직 다운로드 되는 버전은 없습니다.** 지금은 개발 중입니다.

## 리포트로 확인할 수 있는 것

- 검사 기간 동안 성능 한계 수준까지 간 자원은 무엇이었나
- 성능 부족은 주로 어떤 작업에서 발생했나
- 다음 맥을 산다면 어떤 사양을 올려야 하는가

## 개인정보

- 개인정보 입력을 요청하지 않습니다.
- 파일 이름, 창 제목, 인터넷 주소, 문서 내용은 기록하지 않습니다.
- 기록과 리포트는 설치하신 맥 안에만 저장합니다. 인터넷으로 아무것도 보내지 않습니다.
