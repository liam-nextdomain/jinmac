# JinMac

**당신의 맥을 진맥하세요.**

지금 하는 작업을 이 맥이 잘 소화하고 있나요?

JinMac은 평소처럼 맥을 쓰는 1\~2주 동안 메모리·CPU·GPU·디스크·발열을 기록하고,
어느 자원이 얼마나 자주 한계에 닿았는지 한국어 리포트로 알려 줍니다.
다음 맥을 살 때 무엇을 올리고 무엇은 그대로 둬도 되는지 판단할 근거가 됩니다.

---

## 받기

> **아직 받을 수 있는 버전이 없습니다.** 지금은 개발 중입니다.

## 리포트가 답하는 것

- 지난 기간 동안 어느 자원이 얼마나 자주 한계에 닿았는가
- 그때 어떤 작업을 하고 있었는가
- 다음 맥을 산다면 어느 항목을 올리고, 어느 항목은 유지해도 되는가

---

## 개인정보

- 개인정보 입력을 요청하지 않습니다.
- 파일 이름, 창 제목, 인터넷 주소, 문서 내용은 기록하지 않습니다.
- 기록과 리포트는 설치하신 맥 안에만 저장합니다. 업데이트 확인을 빼면 인터넷으로 아무것도 보내지 않습니다.
